# 📓 JournalApp

A modern Android Journal Application developed using **Java**, **Firebase Authentication**, and **Cloud Firestore**. The application allows users to securely register, log in, create personal journal entries, view saved journals, and manage their data with a clean and intuitive user interface.

---

## ✨ Features

- User Registration & Login
- Firebase Authentication
- Cloud Firestore Database
- Create Journal Entries
- View All Journal Entries
- Delete Journal Entries
- Clean & Modern UI
- RecyclerView Implementation
- Responsive Android Layout

---

## 🚀 Installation

1. Clone the repository.

```bash
git clone https://github.com/MaheenAkram/JournalApp.git
```

2. Open the project in Android Studio.

3. Connect your Firebase project.

4. Add your own `google-services.json` file.

5. Sync Gradle and run the application.
